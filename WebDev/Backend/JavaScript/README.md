# 🟨 JavaScript Foundations for Backend

> [!important] Goal
> You do **not** need to become a frontend JavaScript or React expert right now. This module provides the exact core foundations needed to write clean, reliable backend code in [[Introduction to Node.js|Node.js]] and Express.

---

## 📖 Learning Path

1. **[[Variables and Data Types]]**
   - Variables as memory containers
   - `const` vs `let` vs `var`
   - Data types: Strings, Numbers, Booleans, `null`, and `undefined`
   - Useful string utilities: `.toLowerCase()`, `.split()`

2. **[[Objects and Destructuring]]**
   - Object structure and key-value properties
   - Dot notation vs bracket notation
   - Nested objects in API payloads
   - Object Destructuring (`const { fullName, email } = req.body`)

3. **[[Functions and Control Flow]]**
   - Function definitions, parameters, and arguments
   - Functions as first-class values
   - Arrow functions `() => {}`
   - The `return` keyword and early return patterns in API controllers
   - Conditional logic: `if / else` and input validation

4. **[[Async JavaScript and JSON]]**
   - Synchronous vs Asynchronous execution
   - `async` / `await` and Promises
   - JSON format vs JavaScript in-memory Objects
   - How HTTP request bodies are parsed
